# Frühere Konzeptvorschläge

Der hier archivierte Autorisierungsvorschlag wurde vor Bereitstellung der
vollständigen Quelldokumente erstellt. Er ist keine aktive Projektrichtlinie.
Insbesondere war die zusätzliche Ankerbestätigung jedes neuen Geräts ein
Vorschlag, keine bestätigte Produktentscheidung.

Die aktuelle Grundlage ist die
[Identity Authority Policy](../identity-authority-policy.md), deren offene
Entscheidungen im [Security Review](../review-2026-10-08.md) beschrieben sind.
